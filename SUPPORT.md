# Support

wasmquay is maintained in the open on GitHub.

- **Questions and usage help** - open an issue on the repository with the
  `question` label; include the command you ran and what you expected.
- **Bug reports** - use the bug report issue template. Where possible attach
  the `.wasm`, `.wit` or `.pol` input that triggers the problem (keep binaries
  small; the bundled fixtures are a good starting point).
- **Security reports** - follow [`.github/SECURITY.md`](.github/SECURITY.md)
  and use the private "Report a vulnerability" flow on the Security tab; do
  not open a public issue for security problems.
- **Commercial support** - not offered at this time.
- **Chat** - join the `#wasmquay` channel on the community Matrix server for
  quick questions.

There is no chat server and no mailing list; GitHub is the only channel.
